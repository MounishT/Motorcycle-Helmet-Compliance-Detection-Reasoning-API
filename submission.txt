===============================================================================
                        FAILURE CASES SUMMARY
===============================================================================

1. Motion Blur: High-speed riders create blur, causing missed detections.
   Mitigation: Temporal smoothing for video streams.

2. Small Objects: Distant riders (< 32x32 pixels) are missed.
   Mitigation: Multi-scale training, higher resolution input.

3. Occlusion: Blocked riders lead to inaccurate bounding boxes.
   Mitigation: Synthetic occlusion augmentation, NMS tuning.

4. Low-Light: Nighttime scenes cause low confidence detections.
   Mitigation: Histogram equalization, low-light augmentation.

5. Class Confusion: Caps/hats misclassified as helmets.
   Mitigation: Additional negative samples, expanded class definitions.

===============================================================================
                      REPRODUCTION INSTRUCTIONS
===============================================================================

1. Environment Setup:
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   pip install -r requirements.txt

2. Download Model Weights:
   - Place best.pt in weights/ directory
   - Or run: python scripts/download_weights.py

3. Run API:
   uvicorn api.main:app --host 0.0.0.0 --port 8000

4. Test Endpoints:
   curl -F "file=@test.jpg" http://localhost:8000/detect
   curl -F "file=@test.jpg" -F "question=How many helmets?" http://localhost:8000/ask

5. Run Tests:
   pytest tests/ -v
